# M4-R2 블로커 기록

**기록일**: 2026-07-13  
**상태**: STOP — R3 미진입

## 증상

solver-teacher 사전학습으로 초급과 중급은 개선됐지만 고급 direct-transfer가
canonical validation에서 0을 벗어나지 못했다.

| 모델        | 교사 상태/난이도 |          초급 |      중급 |         고급 |
| ----------- | ---------------: | ------------: | --------: | -----------: |
| legacy best |        해당 없음 | 28.5% / 1,000 |        0% |           0% |
| R2 v1       |            2,000 |     37% / 200 |  0% / 200 |     0% / 200 |
| R2 v2       |       추가 6,000 |   71.5% / 200 | 14% / 200 |     0% / 200 |
| R2 v3       |      추가 12,000 |     88% / 100 | 26% / 100 | **0% / 500** |

v3 고급은 평균 생존 수가 약 68수까지 증가했으나 완전 클리어는 없었다. 0/500의
95% Wilson 상한은 약 0.76%다.

## 시도

1. policy/risk/certainty/value 멀티헤드 width96·6블록 모델, 난이도별 2,000 상태.
2. 새 시드 6,000 상태 추가와 policy/risk/certainty 결합 추론.
3. 새 시드 12,000 상태 추가, 순서 반전 rehearsal, learning rate 1e-4.
4. policy-only, risk-only, certainty-only, combined head를 분리 평가했으나 고급은 모두 0%.

## 확인된 개선

- 초급은 legacy canonical 28.5%에서 88%로 상승했다.
- 중급 direct-transfer는 0%에서 26%로 상승했다.
- solver certainty는 입력 채널로 누설하지 않았고 교사 라벨에만 사용했다.
- 기존 solver false-positive-0 코드와 테스트는 변경하지 않았다.

## 가설

- 고급 30x16은 한 판에 필요한 연속 안전 판단 수가 길어 작은 per-step 오류가
  완전 클리어 확률을 0에 가깝게 만든다.
- global average context는 전체 mine budget을 전달하지만 멀리 떨어진 frontier
  component 사이의 구조적 관계를 보존하지 못한다.
- width96 CNN의 확률 calibration과 CSP 장거리 제약 근사가 고급에는 부족하다.

## 필요한 결정

권장안은 R2 내부 아키텍처 escalation이다.

- width128·8블록으로 확대.
- global average만이 아니라 축별 context 또는 lightweight attention을 추가.
- 고급 hard-state oversampling과 component-balanced teacher data 도입.
- 이 변경으로 고급 direct-transfer >0 게이트를 다시 통과한 뒤 R3 masked PPO로 진행.

대안은 고급 direct-transfer 게이트를 M6로 미루는 것이지만, 이는 승인된 R2 게이트를
약화하므로 자동 적용하지 않는다.
