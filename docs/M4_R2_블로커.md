# M4-R2 직접 전이 블로커

**갱신일**: 2026-07-14
**상태**: STOP - R3 실제 학습 미진입

## 결론

승인된 A안(width 128, residual 8블록, 2회 axial attention, constraint-aware
encoding, expert hard-state/component-balanced teacher data)을 구현하고 학습했지만,
고급 policy-only direct-transfer가 canonical validation에서 여전히 0/500이다.

게이트를 낮추거나 R3 학습으로 우회하지 않는다. R3 masked PPO backend는 구현 및 소형
smoke test만 완료했고, 사전 조건을 통과할 때까지 실제 run을 시작하지 않는다.

## 재현 결과

모든 validation은 중앙 첫 클릭, `seed_base=1_000_000_000`을 사용한다.

| 모델          | 교사 상태/난이도 |                 초급 |              중급 |  고급 | 고급 평균 수 |
| ------------- | ---------------: | -------------------: | ----------------: | ----: | -----------: |
| legacy best   |        해당 없음 | 28.5% / 1,000 | 0% |    0% |            - |
| R2 v3 CNN     |      추가 12,000 |         88% / 100 |      26% / 100 | 0/500 |       67.936 |
| **R2-A axial** | **선택 20,000** | **181/200 (90.5%)** | **68/200 (34.0%)** | **0/500** | **88.778** |

R2-A 구간:

- 초급 90.5%, 95% Wilson CI 85.64-93.83%.
- 중급 34.0%, 95% Wilson CI 27.79-40.81%.
- 고급 0/500, 95% Wilson 상한 0.7624%.
- 고급 평균 생존 수는 67.936에서 88.778로 30.7% 증가했지만 완전 클리어는 없다.

## A안 구현

- visible-state 전용 20채널 encoding: 기존 15채널 + 인접 clue constraint 수와
  min/max/mean/spread 위험 통계.
- width 128, 8 dilated residual blocks, row/column attention 2회.
- solver는 teacher label 생성에만 사용하고 inference 입력에는 포함하지 않음.
- 추측 여부, frontier component 수, 진행률 구간으로 후보를 균형 선발.
- 난이도별 후보 60,000개에서 20,000개 선택, 총 60,000 상태, 12 epoch.
- v2 atomic checkpoint와 config/architecture/checksum manifest 유지.

## 추가 head 보정

validation을 계수 선택에 재사용하지 않고 별도 smoke suite
(`seed_base=2_000_000_000`, 32게임)를 사용했다.

| risk weight | certainty weight | 승리 | 평균 수 |
| ----------: | ---------------: | ---: | ------: |
|           3 |                2 | 0/32 |  87.875 |
|           1 |                5 | 0/32 |  85.531 |

두 결합 모두 policy-only보다 개선되지 않아 계수 탐색을 중단했다.

## 유지된 불변식

- solver false-positive-0 코드와 테스트를 변경하지 않음.
- solver 출력은 inference feature가 아님.
- canonical validation seed와 게임 수를 변경하지 않음.
- 체크포인트 및 가중치는 Git에 포함하지 않음.
- 실사이트 자동화는 복구하지 않음.

## 다음 결정 필요

같은 게이트에 대해 데이터 확대, axial 구조, head 보정을 모두 시도했으므로 STOP 규칙을
적용한다. 다음 단계는 사용자 승인 없는 자동 변경 대상이 아니다.

권장 B안은 **명시적 constraint graph policy**다. revealed clue와 hidden frontier를
이분 그래프로 만들고 message passing으로 component별 residual mine constraint를 직접
표현한다. 이는 solver 결론을 입력하는 것이 아니라 보이는 숫자와 연결 관계를 구조화하는
모델 변경이다. B안에서도 고급 direct-transfer >0을 통과한 뒤에만 R3를 활성화한다.
