# M4-R2 직접 전이 블로커

**갱신일**: 2026-07-15
**상태**: RESOLVED - R2-B/R3 게이트 통과

## 결론

R2-A 실패 뒤 visible clue와 hidden frontier의 연결을 recurrent bipartite message
passing으로 표현한 R2-B를 구현했다. canonical validation에서 expert 68/500을 기록해
direct-transfer >0 게이트를 통과했고, 해당 checkpoint에서 R3 masked PPO를 활성화했다.

R3 final best checkpoint는 독립 beginner validation 937/1,000(93.7%), loss 비발산,
bit-identical checkpoint 재로드를 통과했다. 게이트 수치와 seed/game 수는 변경하지 않았다.

## A안 구현

- visible-state 전용 20채널 encoding: 기존 15채널 + 인접 clue constraint 수와
  min/max/mean/spread 위험 통계.
- width 128, 8 dilated residual blocks, row/column attention 2회.
- solver는 teacher label 생성에만 사용하고 inference 입력에는 포함하지 않음.
- 추측 여부, frontier component 수, 진행률 구간으로 후보를 균형 선발.
- 난이도별 후보 60,000개에서 20,000개 선택, 총 60,000 상태, 12 epoch.
- v2 atomic checkpoint와 config/architecture/checksum manifest 유지.

## R2-B 해결 결과

- 모델: width 128, residual 8블록, axial attention 2회 + shared constraint-graph 4회.
- 입력: 기존 visible-only 20채널 유지. solver 결론은 inference 입력에 사용하지 않음.
- 학습: 난이도별 10,000 상태, 16x30 valid-mask padding, mixed shuffled batch, 8 epoch.
- teacher loss: 3.0923에서 2.9113으로 감소, NaN/발산 없음.
- canonical validation:
  - beginner 911/1,000 = 91.1%, 95% Wilson CI 89.17-92.71%.
  - intermediate 131/200 = 65.5%, 95% Wilson CI 58.68-71.74%.
  - expert 68/500 = 13.6%, 95% Wilson CI 10.87-16.88%, 평균 131.948수.
- R3 run: storage/runs/m4-r3-graph, update 200에서 누적 6,510세션과 train win 92.0%.
- R3 smoke: update 10은 30/32, update 20과 update 200은 31/32.
- R3 independent validation: final best beginner 937/1,000 = 93.7%, 95% Wilson CI 92.02-95.05%, 평균 16.682수.
- 재현성: 두 새 모델의 policy/risk/certainty/value tensor가 bit-identical.
- 회귀 검증: server pytest 50 passed, ruff green.

## 유지된 불변식

- solver false-positive-0 코드와 테스트를 변경하지 않음.
- solver 출력은 inference feature가 아님.
- canonical validation seed와 게임 수를 변경하지 않음.
- 체크포인트 및 가중치는 Git에 포함하지 않음.
- 실사이트 자동화는 복구하지 않음.
